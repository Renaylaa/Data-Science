## Projects

### 1. Retail Sales Forecasting & Inventory Planning

**Category:** Time Series Forecasting, Machine Learning, Retail Analytics

Developed a retail sales forecasting solution using the Corporación Favorita dataset to predict product demand across stores and support inventory planning.

**Key Highlights:**
- Performed data preprocessing, exploratory data analysis, and time-based feature engineering.
- Developed and evaluated Seasonal Naive, Random Forest, and XGBoost models.
- Achieved the best forecasting performance using XGBoost, with a WAPE of 14.86%.
- Designed an inventory planning simulation based on forecasted demand, lead time, and safety stock assumptions.
- Built an interactive dashboard to explore sales trends, forecasts, model performance, and inventory recommendations.

**Tools:** Python, Pandas, NumPy, Scikit-learn, XGBoost, Plotly, Streamlit

- [Live Dashboard](https://retail-sales-forecasting-rena.streamlit.app/)

### 2. Student Academic Status Prediction

**Category:** Multiclass Classification, Machine Learning, Educational Analytics

Developed a multiclass classification model to predict student academic outcomes and support early identification of students at risk of dropping out.

**Key Highlights:**
- Used the *Predict Students' Dropout and Academic Success* dataset from the UCI Machine Learning Repository, containing 4,424 student records.
- Performed exploratory data analysis, data preprocessing, and feature engineering.
- Compared Decision Tree, tuned Random Forest, and XGBoost models.
- Achieved the highest overall accuracy of 77.74% using tuned Random Forest, with a Dropout Recall of 0.76.
- Explored an early prediction scenario using Semester 1 data, achieving 72–74% accuracy and 0.72–0.73 Dropout Recall.
- Used SHAP to interpret feature contributions to model predictions.

**Tools:** Python, Pandas, Scikit-learn, XGBoost, SHAP, Google Colab
